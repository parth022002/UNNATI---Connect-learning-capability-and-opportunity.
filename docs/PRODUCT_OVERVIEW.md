# UNNATI — Product overview

## North star
Help people turn potential into meaningful career progress by connecting education, skills, guidance and opportunity.

## Primary audiences
1. Learners and students
2. Early-career talent
3. Working professionals and career switchers
4. Educational institutions
5. Employers and recruiters

## Core product modules
- Unnati Learn — learning paths, resources and projects
- Unnati Careers — career discovery and role exploration
- Unnati AI — explainable AI career assistant
- Unnati Assess — skill and competency assessments
- Unnati Campus — institutional learner development
- Unnati Talent — employer and talent discovery
- Unnati Insights — analytics and reporting

## MVP journey
1. User creates a profile and selects a target career/role.
2. User uploads academic documents (transcripts, syllabus, certificates, resume).
3. System extracts structured education, courses and skills; user reviews/corrects extraction.
4. System maps curriculum and existing capabilities to a skills taxonomy.
5. System compares the user's profile with target-role requirements.
6. System identifies gaps, prerequisites and priority skills.
7. System generates an ordered, explainable roadmap with resources and projects.
8. User tracks progress and updates evidence of capability.

## Explicit non-goals for the first MVP
- Automated job placement guarantees
- Unreviewed high-stakes candidate ranking
- Full enterprise ATS/recruitment suite
- Broad live job-market ingestion before core recommendations are validated
